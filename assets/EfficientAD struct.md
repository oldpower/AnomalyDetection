### 说明

学生网络和教师网络使用的是同一种 PDN 基础架构，区别只在于输出通道数。你之前代码里用的 model_size="small"，对应的就是 PDN-Small：一个约 4 层卷积的极简网络。它和 WideResNet 没有任何结构上的继承关系，唯一的联系是它的权重是通过蒸馏 WideResNet 得到的。

蒸馏 WideResNet-101 来训练 PDN 是一个独立、耗时且资源消耗大的预训练步骤，它需要完整的 ImageNet 数据集和大量 GPU 算力。Anomalib 官方已经替你完成了这一步，把训练好的 PDN 教师权重打包发布在 GitHub Releases 上。

你在训练时看到的“自动下载”，是 Anomalib 检测到本地没有这个预训练教师文件，于是从远程仓库拉取现成的 PDN 权重，而不是在你的机器上现场跑一遍 WideResNet-101 蒸馏。下载完成后，代码会直接把这个权重加载到教师网络里：
```python
teacher_path = pretrained_models_dir / "efficientad_pretrained_weights" / f"pretrained_teacher_{self.model_size}.pth"
self.model.teacher.load_state_dict(torch.load(teacher_path))
```


**WideResNet-101 输出的特征，每个通道的数值范围差异很大，不统一尺度就没法让学生网络好好学。**, WideResNet-101 从 ImageNet 图像上提取出的特征图，不同通道的激活值分布可能天差地别。有的通道输出值普遍在 10 左右，有的可能在 0.1 左右。如果直接拿这些原始特征当目标让学生 PDN 去拟合，学生会被那些数值大的通道“带偏”，学不好数值小但同样重要的通道。

所以论文的做法是：**在蒸馏训练开始前，先“摸底”一遍 WideResNet 特征的统计规律**。具体是遍历一部分 ImageNet 图像，让它们通过 WideResNet-101，统计出**每个通道**的均值 μ 和标准差 σ。这样每个通道就有了一对专属的“缩放参数”。

官方实现里，这一步叫 `feature_normalization`。它先遍历图像算均值，再算方差，最终得到 384 个通道各自的 μ 和 σ。

到了正式蒸馏训练时，每次拿到 WideResNet 的原始特征 `target`，代码里会先做一步：

```python
target = (target - channel_mean) / channel_std
```

这就是标准化：减均值、除标准差。处理完之后，每个通道的数值都被拉到了大致相似的尺度（均值 0、标准差 1 附近）。然后学生 PDN 的输出再去和这个**归一化后的 target** 算 MSE 损失。

这里容易混淆，因为 EfficientAD 里有两套“归一化”：

**特征归一化**：发生在**蒸馏训练 PDN 教师**的阶段，针对的是 **WideResNet 的输出特征**。目的是让学生 PDN 能公平地学习每个通道。产物是 384 个通道的 μ 和 σ，它们最终会被保存进教师 PDN 的权重文件里。

**异常图归一化**：发生在**异常检测训练**阶段，针对的是**学生-教师差异图和 AE 差异图**。用的是验证集上的分位数（0.9 / 0.995）。你训练日志里的 `Calculate Validation Dataset Quantiles` 对应的是这个。

所以，Anomalib 在**官方制作预训练教师权重时**就已经做完的事。你下载到的 `efficientad_pretrained_weights` 里，教师 PDN 的权重已经包含了那组 μ/σ 统计量。你在本地训练异常检测模型时，教师网络前向之后也会用这组保存好的 μ/σ 做一次归一化，然后才和学生输出比差异。
